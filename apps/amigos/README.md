# amigos

Sitio público de **AMIGOS DE MIERDA** en `amigos.brutal.lat` (test: `test-amigos.brutal.lat`). Cuenta el juego y cuenta BRUTAL, en el tono de Cards Against Humanity.

- `/` — el juego, las reglas, algunas cartas, "Tus preguntas estúpidas" y qué es BRUTAL.
- `/jugar` — redirige a WhatsApp con "Quiero jugar con mi grupo" escrito. Es el link de todas las placas: si cambia el número, se cambia la variable.
- `/cartas` — todas las cartas de la biblioteca, para imprimir.

Variables: `AMIGOS_PUBLIC_NUMBER` (el número del juego, dígitos), `API_URL` (de ahí salen las cartas), `BRUTAL_ENV`.
